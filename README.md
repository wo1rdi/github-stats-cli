# GitHub Profile Analyzer 🔍

Простой и полезный скрипт на Python для анализа публичных профилей GitHub **без использования токенов**.

## Что он умеет:
* Показывает базовую информацию (Имя, био, количество подписчиков).
* Выводит список последних репозиториев.
* Анализирует стек и выводит статистику по языкам программирования.

## Как запустить:
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите скрипт: `python github_analyzer.py`
3. Введите никнейм любого пользователя GitHub.
